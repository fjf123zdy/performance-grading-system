# 合成革企业环境绩效分级评价系统 V1.0

## 📋 项目简介

本系统基于中国环境科学研究院编制的《合成革企业环境管理与排放水平绩效分级政策建议研究报告》（2025年12月），将合成革企业环保绩效分级指标体系数字化，实现对合成革企业环境管理与排放水平的科学量化评价和自动分级。

系统建立了合成革企业的绩效分级指标体系，涵盖**基本要求判定**、**定量指标计算**、**定性指标评分**三大评价维度，并采用**层次分析法（AHP）**与**粒子群优化算法（PSO）**相结合的群决策方法确定指标权重，最终将企业划分为三个等级：**一级（引领级）**、**二级（先进级）**、**三级（基础级）**。

## ✨ 核心功能

### 1. 企业基本要求判定
- 五项一票否决制审查
- 近三年无环境/安全/质量事故
- 未列入失信名录
- 废水排口规范化建设合规

### 2. 定量指标计算
- **标准品产量折算**：按厚度×幅宽二维系数表折算
- **单位产品废水产生量**：Vci = Vc / Qbz
- **单位产品 VOCs 产生量**：VOCs = Gvoc / Qbz
- **DMF 有组织排放浓度**：建议限值 ≤20mg/m³
- **非封闭区域 VOC 检测值**：无组织排放管控

### 3. 定性指标评分
6 个一级指标、15 个二级指标，每项 0-10 分制：
- 原辅材料准备（自动配料系统、管道密闭输送）
- 废气治理（包围型收集装置、喷淋塔、精馏塔、无组织控制）
- 废水收集和处理（密闭管道、接入口隔离）
- 初期雨水收集和处理（晴天清空、液位显示、超滤膜回用）
- 固废管理（危废规范化、一般固废资源化）
- 检测监控要求（废水/废气在线监测、厂界无组织监测）

### 4. AHP 层次分析法
- 1-9 Saaty 标度法构造判断矩阵
- 和积法求解权重向量
- 幂迭代法交叉验证
- 一致性检验（CR < 0.1）
- 层次总排序

### 5. PSO 粒子群优化算法
- 修正不满足一致性的专家打分矩阵
- 适应度函数：fitness = α×|CR| + β×||A'-A_original||
- 惯性权重线性递减（0.9→0.4）
- 实时收敛曲线输出

### 6. 群决策融合
- **直接均值法**：多专家权重算术平均
- **群决策矩阵法**：矩阵元素几何平均后再做 AHP
- 支持 2-10 位专家

### 7. 分级结果展示
- 三级分类：🥇 引领级 / 🥈 先进级 / 🥉 基础级
- 等级徽章 + 各维度详情
- 差异化管控措施建议
- 综合报告一键生成

### 8. 企业管理
- 5 家预设模拟企业（覆盖各级别）
- **新增企业**：填写基本信息后自动生成评价数据
- **删除企业**：支持删除企业及关联评价记录
- 新增企业自动继承完整评价流程

## 📊 评价流程

```
选择企业 → 基本判定 → 定量指标 → 定性指标 → AHP权重 → PSO优化 → 群决策 → 分级结果
```

### 分级标准

| 等级 | 名称 | 定量指标 | 定性评分 | 管控措施 |
|------|------|----------|----------|----------|
| 一级 | 引领级 | 全部达到一级阈值 | ≥85% | 预警期自主减排，可扩大产能，享税收优惠 |
| 二级 | 先进级 | 全部达到二级阈值 | ≥70% | 黄/橙预警停产50%，维持现有产能 |
| 三级 | 基础级 | 全部达到三级阈值 | ≥60% | 连续两年三级须整改，逾期缩减产能 |
